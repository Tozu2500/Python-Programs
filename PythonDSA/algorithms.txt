🧮 1. Basic Algorithms (Searching, Sorting, Utility)

Linear Search – Sequentially checks every element for a match.

Binary Search – Searches a sorted list by repeatedly dividing the range in half.

Jump Search – Moves ahead by fixed steps, then linear search.

Interpolation Search – Predicts probable position using interpolation.

Exponential Search – Finds a range exponentially before binary search.

Bubble Sort – Swaps adjacent elements if out of order.

Selection Sort – Repeatedly finds the minimum element.

Insertion Sort – Builds a sorted list one element at a time.

Merge Sort – Divide & conquer sorting via merging sorted halves.

Quick Sort – Partitions elements around a pivot recursively.

Heap Sort – Uses a max-heap to repeatedly extract the largest.

Counting Sort – Non-comparison sorting by counting occurrences.

Radix Sort – Sorts integers digit by digit.

Bucket Sort – Divides data into buckets, sorts individually.

Shell Sort – Insertion sort using gaps to reduce comparisons.

Comb Sort – Improves bubble sort using gap shrinking.

Tim Sort – Python’s built-in sort (hybrid merge/insertion).

Cycle Sort – Minimizes write operations during sorting.

Pancake Sort – Sorts using prefix reversals.

Stooge Sort – Recursive sorting method (educational example).

Stack Operations (Push/Pop) – LIFO stack operations.

Queue Operations (Enqueue/Dequeue) – FIFO structure.

Deque Operations – Insert/remove from both ends.

Priority Queue (Heapq) – Elements retrieved by priority.

Linked List Traversal – Iterate through nodes.

Linked List Reversal – Reverse nodes in place.

Detect Loop in Linked List – Floyd’s cycle detection.

Merge Two Sorted Lists – Combine linked lists efficiently.

Binary Tree Traversal (Inorder) – Left-root-right order.

Preorder Traversal – Root-left-right order.

Postorder Traversal – Left-right-root order.

Level Order Traversal – BFS-style tree traversal.

Height of Binary Tree – Computes maximum depth.

Balanced Binary Tree Check – Ensures balanced height.

BST Insertion/Deletion – Maintain BST properties.

AVL Tree Rotations – Rebalance after insert/delete.

Trie Insert/Search – Prefix tree for word search.

LRU Cache – Least recently used cache using OrderedDict.

Hash Table Implementation – Custom hash map in Python.

Union-Find (Disjoint Set) – Efficient set merging & lookup.

Greatest Common Divisor (Euclid) – Efficient GCD computation.

Least Common Multiple (LCM) – Using GCD relation.

Sieve of Eratosthenes – Generate primes up to N.

Prime Factorization – Decompose integer into prime factors.

Check Prime – Determine primality.

Modular Exponentiation – Compute (a^b) mod n efficiently.

Fibonacci (DP) – Iterative dynamic programming version.

Factorial (Recursive/Iterative) – Compute n!.

Palindrome Number Check – Check if digits form palindrome.

Armstrong Number Check – Validate number equal to sum of power of digits.

Power of Two Check – Bitwise or math check.

N-th Root Calculation – Compute integer or float roots.

Matrix Multiplication – Standard 2D matrix product.

Fast Matrix Power – Matrix exponentiation.

Determinant Calculation – Recursive determinant of a matrix.

Permutation Generator – All possible orderings.

Combination Generator – All subset combinations.

Binomial Coefficient (nCr) – Pascal’s triangle or DP.

Pascal’s Triangle – Generate all rows up to n.

Catalan Number – Recursive DP combinatorial number.

Count Vowels/Consonants – String analysis.

Substring Search (Naive) – Brute-force find substring.

Edit Distance (Levenshtein) – Minimum edit operations between strings.

String Compression (RLE) – Run-length encoding.

Caesar Cipher – Simple letter shift cipher.

Count Substrings – Count distinct substrings.
